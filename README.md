# 냉장고를 부탁해 🥬

우리 집 냉장·냉동 재료를 기록하고, 먼저 소비할 재료로 오늘의 한 끼를 추천하는 **HTML · CSS · JavaScript 웹 앱**입니다.

**[앱 열기 · Vercel](https://please-fridge.vercel.app/)** — 개인 키 입력 없이 유튜브 자동 연결

[GitHub Pages 정적 버전](https://dorothychoi8857.github.io/please-fridge/)도 유지합니다. 정적 버전은 개인 키 또는 유튜브 검색 링크를 사용합니다.

## 주요 기능

- 구매 묶음별 재료 등록·수정·삭제와 냉장/냉동 구분
- 제품 표시 날짜와 근거 기반 권장 소비 시점 구분
- 소비 우선순위, 부족한 재료·수량 및 보유 대체재 안내
- 샘플 레시피 6개, 장보기 목록, 요리 후 재고 차감과 되돌리기
- 기본 양념 보유 가정, 알레르기·식단·제외 재료 설정
- 모바일 하단 메뉴·재료 추가 버튼·입력 시트
- 브라우저 자동 저장, JSON 백업 내보내기·불러오기
- 선택적인 YouTube 영상 검색 또는 키 없는 YouTube 검색 링크

## 실행

GitHub Pages 링크를 열거나, 저장소를 다운로드해 `index.html`을 Chrome/Edge로 여세요. 서버·Python·Node.js·빌드 과정이 필요하지 않습니다. 이미지와 JS·CSS가 포함된 폴더 전체를 함께 보관하세요.

모바일에서는 실제 브라우저로 열어 주세요. 파일 미리보기 앱은 JavaScript를 실행하지 않을 수 있습니다.

## Vercel에서는 유튜브 자동 연결

Vercel 배포에서는 서버 환경변수 `YOUTUBE_API_KEY`를 사용합니다. 방문자는 개인 키를 입력하지 않아도 메뉴별 영상을 볼 수 있습니다. `api/`의 **JavaScript 서버 함수**가 Google에 요청하고 브라우저에는 영상 정보만 반환합니다. Python이나 외부 서버 패키지는 필요하지 않습니다.

- `YOUTUBE_API_KEY`는 Vercel의 **Production Secret**으로만 설정하고 저장소·HTML·클라이언트 JS에 넣지 않습니다.
- 메뉴는 등록된 6개로 제한하고, 제목의 핵심어로 관련성을 확인한 뒤 조회수 높은 최대 3개를 표시합니다.
- 메모리·CDN 캐시로 반복 요청을 줄입니다. Google API나 Vercel Hobby의 무료 할당량이 초과되면 이용이 제한될 수 있습니다.
- `api/status`는 준비 여부만 반환하며 실제 키 값은 반환하지 않습니다.
- GitHub Pages와 `file://` 버전은 서버 기능 없이 기존 개인 키 방식 또는 키 없는 검색 링크로 동작합니다.

## 데이터와 보안

- 재고는 **현재 브라우저의 localStorage**에만 저장됩니다. 로그인·원격 DB·기기 간 동기화는 없습니다.
- 브라우저 데이터 삭제나 다른 기기 사용 시 재고가 사라지거나 보이지 않을 수 있습니다. JSON 백업을 권장합니다.
- **실제 API 키·`.env`·개인 재고는 이 저장소에 포함하지 않습니다.**
- YouTube 키를 직접 입력하면 현재 탭의 sessionStorage에만 보관하며, 재고 백업에는 넣지 않습니다.
- **브라우저에 직접 입력한 개인 키는 숨길 수 없습니다.** Vercel의 서버 자동 연결에서는 브라우저에 키를 전달하지 않습니다. 개인 키 입력은 개인 PC에서만 사용하고, 공용 환경에서는 서버 연결 또는 키 없는 검색 링크 방식을 권장합니다.
- 개인 키 사용 시 YouTube Data API v3만 허용하고, 웹사이트 제한은 본인이 사용하는 배포 주소에 맞게 설정하세요.
- 사진 분석은 보류 상태이며, 이 버전은 OpenAI API를 호출하지 않습니다.

## 식품·레시피 안내

권장 소비 시점은 확인된 일부 품목의 공개 보관 지침을 적용한 추정이며 안전을 보장하지 않습니다. 국내 제품의 표시와 실제 보관 상태를 우선 확인하세요. 기한 경과·변질 의심·상태 미확인 식품은 추천에서 제외합니다.

추천 메뉴·분량·조리 순서는 등록된 샘플이며 유튜브 영상에서 추출한 정보가 아닙니다. 영상 속 재료와 조리법은 다를 수 있으므로 실제 사용량을 확인하세요.

## 파일 구성과 테스트

| 파일 | 역할 |
|---|---|
| `index.html` | 시작 화면 |
| `styles.css`, `mobile.css` | PC·모바일 UI |
| `data.js` | 재료·레시피·보관 정보 |
| `engine.js` | 날짜·수량·추천·백업 검증 |
| `youtube.js` | 선택적 Google API 직접 연결 |
| `api/status.js`, `api/youtube.js` | Vercel용 JavaScript 서버 함수 · 키를 서버에만 보관 |
| `vercel.json` | Vercel 배포 설정 |
| `app.js` | 화면·이벤트·저장 |
| `tests.html`, `tests.js` | 브라우저 로직 테스트 |

`tests.html`을 브라우저로 열면 로직 테스트를 실행할 수 있습니다.

서버 함수 테스트는 Node.js에서 `node --test scripts/api.test.cjs`로 실행합니다. 모의 API 응답만 사용하고 실제 키나 할당량을 사용하지 않습니다.

## 배포

Vercel 프로젝트는 GitHub 저장소의 `main` 브랜치와 연결되어 있습니다. 푸시하면 운영 사이트가 자동으로 갱신됩니다. CLI로 배포할 때는 이 폴더에서 `vercel deploy --prod`를 사용합니다. Windows PowerShell 실행 정책으로 스크립트가 차단되면 `vercel.cmd deploy --prod`를 사용하세요.

`.vercelignore`와 `.gitignore`로 `.env*`, 인증 파일, 개인 재고 백업, 로컬 Vercel 메타데이터를 제외합니다. `YOUTUBE_API_KEY`는 Vercel Production 환경의 Secret으로 관리하며 값을 코드에 복사하지 않습니다.

외부 사진의 저작권과 라이선스는 각 출처에 따릅니다.
