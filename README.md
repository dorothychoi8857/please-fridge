# 냉장고를 부탁해 🥬

우리 집 냉장·냉동 재료를 기록하고, 먼저 소비할 재료로 오늘의 한 끼를 추천하는 **HTML · CSS · JavaScript 웹 앱**입니다.

**[앱 열기](https://dorothychoi8857.github.io/please-fridge/)**

## 주요 기능

- 구매 묶음별 재료 등록·수정·삭제와 냉장/냉동 구분
- 제품 표시 날짜와 근거 기반 권장 소비 시점 구분
- 소비 우선순위, 부족한 재료·수량 및 보유 대체재 안내
- 샘플 레시피 6개, 장보기 목록, 요리 후 재고 차감과 되돌리기
- 기본 양념 보유 가정, 알레르기·식단·제외 재료 설정
- 모바일 하단 메뉴·재료 추가 버튼·입력 시트
- 브라우저 자동 저장, JSON 백업 내보내기·불러오기
- 선택적인 YouTube 영상 검색 또는 키 없는 YouTube 검색 링크

## 실행

GitHub Pages 링크를 열거나, 저장소를 다운로드해 `index.html`을 Chrome/Edge로 여세요. 서버·Python·Node.js·빌드 과정이 필요하지 않습니다. 이미지와 JS·CSS가 포함된 폴더 전체를 함께 보관하세요.

모바일에서는 실제 브라우저로 열어 주세요. 파일 미리보기 앱은 JavaScript를 실행하지 않을 수 있습니다.

## 데이터와 보안

- 재고는 **현재 브라우저의 localStorage**에만 저장됩니다. 로그인·원격 DB·기기 간 동기화는 없습니다.
- 브라우저 데이터 삭제나 다른 기기 사용 시 재고가 사라지거나 보이지 않을 수 있습니다. JSON 백업을 권장합니다.
- **실제 API 키·`.env`·개인 재고는 이 저장소에 포함하지 않습니다.**
- YouTube 키를 직접 입력하면 현재 탭의 sessionStorage에만 보관하며, 재고 백업에는 넣지 않습니다.
- **브라우저에서는 키를 숨길 수 없습니다.** 개인 PC에서만 입력하고, 공용 환경에서는 키 없는 검색 링크 방식을 권장합니다.
- 개인 키 사용 시 YouTube Data API v3만 허용하고, 웹사이트 제한은 본인이 사용하는 배포 주소에 맞게 설정하세요.
- 사진 분석은 보류 상태이며, 이 버전은 OpenAI API를 호출하지 않습니다.

## 식품·레시피 안내

권장 소비 시점은 확인된 일부 품목의 공개 보관 지침을 적용한 추정이며 안전을 보장하지 않습니다. 국내 제품의 표시와 실제 보관 상태를 우선 확인하세요. 기한 경과·변질 의심·상태 미확인 식품은 추천에서 제외합니다.

추천 메뉴·분량·조리 순서는 등록된 샘플이며 유튜브 영상에서 추출한 정보가 아닙니다. 영상 속 재료와 조리법은 다를 수 있으므로 실제 사용량을 확인하세요.

## 파일 구성과 테스트

| 파일 | 역할 |
|---|---|
| `index.html` | 시작 화면 |
| `styles.css`, `mobile.css` | PC·모바일 UI |
| `data.js` | 재료·레시피·보관 정보 |
| `engine.js` | 날짜·수량·추천·백업 검증 |
| `youtube.js` | 선택적 Google API 직접 연결 |
| `app.js` | 화면·이벤트·저장 |
| `tests.html`, `tests.js` | 브라우저 로직 테스트 |

`tests.html`을 브라우저로 열면 로직 테스트를 실행할 수 있습니다.
